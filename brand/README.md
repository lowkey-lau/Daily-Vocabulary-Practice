# 拾乡音 · 品牌素材

## 头像

| 文件 | 用途 |
| --- | --- |
| `avatar-144.png` | **推荐上传**，144×144 PNG，符合微信要求 |
| `avatar-512.png` | 高清主图 / 备份 |
| `avatar-b-144.png` | 备选 B：米色底 + 玉色圆 |
| `avatar-c-144.png` | 备选 C：米色底 + 玉色圆角方块 |
| `contact-sheet.png` | A / B / C 三版对比 |
| `circle-preview.png` | 微信圆形头像预览 |

**推荐 A 版**：玉色底 + 米白「乡」+ 金色声波 + 珊瑚点。

- 「乡」代表家乡话 / 乡音
- 声波代表长辈录音、把声音留下来
- 全底色在圆形裁切下不会露出白边，小尺寸也清楚
- 图片为原创几何图形 + 单字，不含政治 / 色情 / 第三方标识

上传时选择 `avatar-144.png` 即可，PNG 且小于 2MB。

## 设计含义

「拾」是捡起、留住；「乡音」是家乡话。头像用「乡」+ 声波，表达把家里的声音拾起来、留下来。
