# 每日单词练习小程序

面向碎片时间学习的粤语词汇练习微信小程序。第一版以「看词选义」为核心题型，每天 3–5 分钟，学几个词也算数；数据模型保留多语言 / 方言扩展能力。

## MVP 范围

- 微信小程序，静默登录，云端持久化
- 首发粤语，1 本入门词书（200–300 词）
- 语言 / 方言 → 词书 → 词条 三层内容模型，保留多语言扩展能力
- 每日建议：3–5 个新词 + 到期复习，学几个也算
- 看词选义：一屏一题、四选一、即时反馈与解析
- 单词发音：第三方 TTS 预生成粤语音频
- 结果页、连续学习天数、错词本、基础统计
- 内容导入：JSON + 本地脚本批量导入与发布（小程序内管理界面 P1）

详细功能与验收标准见 [PRD](docs/PRD.md)。

## 规划中的技术栈

- 微信原生小程序 + TypeScript
- 微信云开发：云数据库 / 云函数 / 云存储
- 内容通过 JSON 批量导入，管理员 openid 白名单
- 第三方 TTS（腾讯云 / Qwen3-TTS 备选）预生成音频，存入云存储
