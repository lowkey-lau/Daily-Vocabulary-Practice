## 模块文档约定

1. 每个模块头部写清楚：版本、状态、负责人、关联主 PRD。
2. 模块文档只写该模块的细节；整体定位、范围、指标回到主 PRD。
3. 模块决策变化时，同步更新主 PRD 的摘要或变更记录。
4. 涉及云端、支付、未成年隐私的模块，必须写清楚边界和待确认项。
5. 商业化目前只是规划，**当前版本不收费**。
