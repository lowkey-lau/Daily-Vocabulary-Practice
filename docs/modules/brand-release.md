## 3. 类目建议

- 优先考虑偏「工具」的类目，避免「教育 / 培训 / 课程」带来的资质要求。
- 名称和介绍已经避开教育词；但**实际类目以微信公众平台最新要求为准**。
- 如果后续做课程、训练营、老师端，需要重新评估教育类目和资质。

---

## 4. 隐私与儿童保护

- 录音前明确说明用途、可见范围、删除方式。
- 默认家庭私有，不公开搜索、不进入推荐。
- 长辈可删除自己的录音；家庭可整体删除。
- 学习者如果是儿童：账号主体为家长，不采集儿童身份信息，不开放公开主页/评论。
- TTS/真人录音的商用授权、声音版权单独确认。
